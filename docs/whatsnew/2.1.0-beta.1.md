# What's new (since 2.0.0)

- Fonts: Classic can now use Atkinson Hyperlegible Next, Noto Sans or Literata (Settings > Style > Font).
- Quick sizes: hold a pen or the eraser on the toolbar to pick its size, or switch the eraser between Whole strokes and Precise.
- Folders: moving or renaming a folder onto one with the same name offers Merge into it or Keep both.
- Dense pages open instantly again after you write on them, and closing a notebook is quicker.
- Clear page and a new paper or template no longer show the old picture.
- Read all lists every version's notes, each on one screen.
