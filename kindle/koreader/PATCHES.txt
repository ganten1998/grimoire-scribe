KOReader patches supplied with Grimoire

Use Grimoire > Library > Settings > KOReader to apply or remove each patch. Restart KOReader
once after changing them. The patches are optional; installing the Grimoire plugin does not
apply them. Existing different patches at the same filename are kept.

- 2-no-diagonal-screenshot.lua: disables the two diagonal screenshot gestures.
- 2-mosaic-square-corners.lua: square folder tiles in Cover browser's mosaic view.
- 2-terminess-ui-font.lua: Terminess / Terminus menus, a matched regular/bold font family,
  and spacing between the dropdown menu's battery icon and percentage. Battery status and reading
  footers use KOReader's native font fallback so charging/unplugged symbols remain correct. Grimoire supplies
  Terminess with its OFL, and the Apache-2.0 notice of its icons. Since 2.0.0-beta.2 the font holds only
  Terminus's text and Grimoire's own icons, so KOReader's battery symbols come from its own symbols font, and
  Grimoire brings the copy in KOReader's fonts/Grimoire up to date when it starts. This updates the script
  shipped with 1.1.0-beta.1 and 1.1.0-beta.2.
  Since 2.0.0-beta.2 the menus use Grimoire's own copy in fonts/Grimoire whenever it is there, even with
  other Terminess or Terminus files in the Kindle's fonts folder. A full Nerd Font has its own icons where
  KOReader's battery symbols are (a "JS" badge, for one), so without Grimoire's copy such a font is passed
  over while another will do. koreader/crash.log names the font the menus use and why others were passed
  over. A start of Grimoire also replaces an earlier Grimoire copy of this script in KOReader's patches
  with the current one, if that copy is byte for byte as Grimoire wrote it (grimoire.log says so once).

Manual installation: copy only the .lua files you want into your KOReader installation's patches/
folder. Copy fonts/Grimoire/ into its fonts/ folder. Restart KOReader. Remove a .lua file and
restart to undo that patch. The font files can stay; without the patch they change no menus.
The screenshot and square-corner scripts are unchanged since 1.1.0-beta.1. The Terminess script
has been updated. A byte-exact earlier Grimoire Terminess patch is upgraded at Grimoire's next
start, or from Settings; a locally modified copy is preserved.
