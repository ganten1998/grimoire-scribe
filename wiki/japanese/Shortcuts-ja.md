# キーボードとコントローラーのショートカット

コントローラー（またはキーボード）は、ペンを持っていない方の手のための専用キーです。ページ、
ツール、元に戻す／やり直す、消しゴムと白インク、リンク、ページ名をノートエディターで操作できます。
エディターのメニューを開いたり閉じたりはできますが、メニュー内の移動はできません（ツールピッカーの
次／前を除く）。そこはタップしてください。

**ライブラリ > 設定 > ショートカット > ショートカットを有効にする** をオンにします。これにより、
`/mnt/us/grimoire/shortcuts.ini` が存在しない場合にだけ、初期マッピングが書き込まれます。
USB／SSH で編集し、**shortcuts.ini を再読み込み** を選ぶと、読み込んだマッピング数と拒否された
行数が表示されます。シートにはキーボードとコントローラーの一覧、最後のキー／ボタンコードが
表示されます。ショートカットを無効にすると、任意の入力デバイスを再び閉じます。

設定の上部の行は **表示**、**ペン感度**、**ショートカット**、**ペンとタッチのキャリブレーション**
の順です。下部の **ペアリング** は Bluetooth の項目（Bluetooth コントローラー、コントローラーを
ペアリング...、接続中のデバイス名）を開きます。

## キーボードの割り当て

Kindle に接続したキーボードには 1 つの割り当てがあります。Apple キーボードの Cmd は Kindle では
Meta として報告され、Meta を押したキーに対応する行がない場合は Ctrl に置き換えて探し直すため、
Cmd+Z も元に戻すになります。ショートカットはオプトインのままです。

キーは場所ごとに別の意味を持てます。**ライブラリ**（および共有画面。Esc だけが動作）、
**ノートのページ**（上に開いているメニューに関係なく）、**ページビュー**、**グラフ**、
**ペン感度** です。

| 場所 | キー |
|---|---|
| すべて | Esc `back`、Ctrl+S `save` |
| ライブラリ | Ctrl+N `new-notebook`、Ctrl+F `new-folder`、S `share`、O `settings`、左右の画面、G グラフ |
| ノートのページ | 1〜9 ペン、0 と E 消しゴム、W 白インク、Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y 元に戻す・やり直す、左右と PageUp/PageDown ページ、Home/End、[ と ] ツール、Shift+[ と Shift+] ペンの太さ、Ctrl+N `new-page`、Ctrl+F `go-to-page`、Ctrl+L `add-link`、R `name-page`、Space `two-finger-up`、- と = ズーム、Ctrl+0 ページ全体、G L P T S、X 長押しで消去 |
| ページビュー | 左右の画面、Ctrl+N、Ctrl+F、Ctrl+A `select-all`、Ctrl+Z と Ctrl+Shift+Z ページビュー自身の元に戻す／やり直す、P、G |
| グラフ | 矢印 `pan-*`、- と +、Ctrl+0、V `graph-view`、Ctrl+A、G |
| ペン感度 | 1〜9 そのペンのタブ、0 と E 消しゴム |
| キーボード表示中 | 左右でキャレットを 1 文字、Home/End で先頭と末尾（Shift で選択）、Ctrl または Cmd と A、C、X、V で入力テキストの全選択、コピー、切り取り、貼り付け。これらはショートカットより優先され、再割り当てできません。枚数パッドでは使えません |

**Esc** は 1 押しにつき 1 層閉じます。入力欄やパッド、ダイアログやカード、ドラッグ、選択、メニュー
やシート、リンク配置、そしてノートからライブラリへ、ペン感度や共有から戻る、フォルダから一番上へ、
ライブラリの一番上では **Grimoire を終了しますか？** です。**Space** はそこで 2 本指を上に
スワイプしたときと同じ動作をします。**Ctrl+S** はページとノートをすぐに書き込みます。**R** は
ページ名のキーボードを開きます。

## デバイスごとのプロファイル

USB でも Bluetooth でも、キーボードやコントローラーごとに独自のショートカットを保存し、接続する
たびに使えます。独自の設定がないデバイスは初期値（`shortcuts.ini` と `controller.ini`）を
使います。

**設定 > ショートカット** には **デバイス**、**このデバイス専用のショートカット**、
**ボタン...**、**shortcuts.ini を再読み込み**、最後の入力、完了があります。
**このデバイス専用のショートカット** をオンにすると、初回は初期設定のコピーから始まるので、
変更するまでは今までと同じ動作です。オフにすると再び初期設定を使い、プロファイルは保持されます。
ファイルは `/mnt/us/grimoire/shortcuts/` に、デバイスのスラッグ（名前を小文字にし、その他の文字の
連続を `-` にし、ベンダーと製品番号を 16 進で付けたもの。例:
`8bitdo-pro-2-2dc8-6006`）で保存されます。最大 32 プロファイルまで読み込みます。

## コントローラーのボタン

**設定 > ショートカット > ボタン...** は各ボタンの動作を表示し、新しい割り当てを学習します。
一覧には **編集**、**ツール**、**ページ**、**インデックス**、**メニュー**、**画面**、
**システム** の 7 グループがあります。グループを開き、行をタップしてからボタンを押します。
完了で一覧に戻ります。1 つのボタンには 1 つの動作だけです。別の動作をしていたボタンは今後この
動作になり（どの動作を失ったかトーストで表示）、その動作の他のボタンは動作しなくなります。
前／次と最初／最後の行は 2 回の押下（1 つ目と 2 つ目）を学習します。10 秒間押下がないと行は
元のままです。行を長押し（0.6 秒）するとその行のボタンを外せます。**ボタンをリセット** は
`controller.ini` を削除します。

Xbox レイアウトのコントローラーのトリガーは LT と RT というボタンとして読み取られます。
Switch モードのコントローラーは Pro Controller の順序（B、A、Y、X、L、R、ZL、ZR、-、+、LS、
RS、Home、Capture）で番号を振ります。シートにはそのラベルが表示され、ファイルには番号が保存
されます。

`/mnt/us/grimoire/controller.ini` には学習したボタンが保存されます。このファイルがある間は
コントローラーのボタンはこのファイルだけから読み込まれ、`shortcuts.ini` の `pad.` 行は脇に
置かれます。キーボード（`key.`）の行は常に `shortcuts.ini` から読み込まれます。

## shortcuts.ini

初期のキーボード設定では、1〜9 がツールピッカーの順（鉛筆、シャープペンシル、木炭、ボールペン、
細書きペン、マーカー、万年筆、カリグラフィーペン、ハイライター）の 9 つの描画ツール、0 と E が
消しゴム、W が白インク、Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y が元に戻す／やり直す、左右と
PageUp/PageDown がページ、[ と ] がツールの切り替え、Shift+[ と Shift+] がペンの太さです。

ゲームパッドの初期値は Linux のゲームパッド規約に従います。South が元に戻す、East が消しゴム、
North がやり直す、West が白インク、L1/R1 が前／次のツール、Select/Start が前／次のページ、
D-pad の左右がページ、上下がツールです。これらは出発点です。それ以外は **ボタン...** で設定
します。

```ini
key.1=tool:pencil
key.Ctrl+z=undo
key.Shift+Left=previous-page
key.code106=next-page
key.Ctrl+i=index
pad.East=tool:eraser
```

古いバージョンでは新しい動作名（`save`、`back`、`two-finger-up`、`new-notebook`、
`new-folder`、`share`、`settings` など 2.0.0-beta.2 のもの）は 1 行ずつ拒否されます。
