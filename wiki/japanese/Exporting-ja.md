# Kindle からページを取り出す

方法は 3 つあります。どれも同じレンダラーを使うので、ページは Kindle 上でも PNG でも PDF でも
同じ見た目になります。

## Wi-Fi: インストール不要

Kindle で Wi-Fi をオンにし（**設定 > Wi-Fi** でネットワークも選べます）、**ライブラリ > 共有**
を開きます。QR コードと、その下に大きく同じアドレス（例: `http://192.168.1.23:8765`）が表示
されます。スマートフォンのカメラをコードに向けるか、同じネットワーク上のパソコンやスマートフォンの
ブラウザでアドレスを開きます。

- すべてのフォルダとノートがサムネイル付きで表示されます
- ノートごと: **PDF**、**ZIP**（PDF + ページごとの PNG + 生ファイル）、**エフェクト**（下記）、
  1 ページずつ表示するリーダー（上部にページカウンターと番号入力）
- フォルダごと: zip。上部には **すべてダウンロード**

ダウンロード中は共有画面を開いたままにしてください。離れるとサーバーが停止します。共有画面で
Kindle がスリープすると、新しいリクエストには応答しません。そのとき要求されたページは待機し、
ブラウザがあきらめていなければスリープ解除後に読み込まれます。

ページは Grimoire の表示言語で出力されます。ダウンロードのファイル名とスクリプト用エンドポイントは
どの言語でも同じです。ZIP 内の生ファイルは、ノートの `notebook.ini`、本への書き込みなら
`source.ini`、`p<id>.qpg` ページ、画像（`bg/`）です。

どの書き出しも、作成した Kindle に関係なくノートのページサイズ（1860x2480 または 1986x2648）に
なります。

### エフェクト

**エフェクト**（各ノート、および各ページの下）は、ページの新しい画像を作るスタジオです。Kindle は
各ページを空の用紙とインクだけの 2 レイヤーで送り、ブラウザが好みに合わせて組み直します。

- **背景**: 白、透明、単色、グラデーション
- **用紙の線**: 表示／非表示、色と強さを自由に
- **インク**: そのまま、単色、文字に沿ったグラデーション
- **ルック**: トーン、暖かさ、色合い、明るさ、コントラスト
- **切り抜きとサイズ**: ページ全体、またはインク＋余白に合わせて切り抜き。100%、50%、25%
- **プリセット**: 透明、署名、暖色、セピア、羊皮紙、青写真、黒板、夜、夕焼けインク、オーロラ

表示中のページを PNG で、または全ページを PNG の zip か 1 つの PDF でダウンロードできます。
透明 PNG はインクの柔らかい縁（鉛筆の粒、軽い筆圧）を半透明として保つので、どんな背景にも
きれいに重なります。ブラウザは最後の設定を覚えています。各操作は ImageMagick の 1 操作で、
スタジオは同じ画像を作る `magick` コマンドを表示します。

セキュリティ: サーバーにパスワードはありません。共有画面を開いている間だけ待ち受け、ファイア
ウォールの穴は Wi-Fi インターフェースだけに開き、読み取り専用（GET）で、`Host` が IP アドレス
でないリクエストは拒否します。信頼できないネットワークで共有を開かないでください。

## USB ケーブル

**設定 > PDF を grimoire/PDFs に複製** がオン（初期値）のとき、ノートを閉じるとバックグラウンドで
`grimoire/PDFs/<フォルダ>/<名前>.pdf` が書き出されます。ノートの名前変更、移動、削除に合わせて
PDF も移動・削除されます。Kindle を接続してコピーしてください。

すべてが必要なら、生のノートは `grimoire` フォルダにあります。PDF は `documents/` の外に置かれ、
Kindle がインデックスを作らないようになっています。

## ターミナルから

```sh
tools/grimoire-pull --http 192.168.1.23     # Wi-Fi 経由（共有画面を開いたまま）、SSH 不要
tools/grimoire-pull                         # SSH 経由: rsync + ここでレンダリング
tools/grimoire-pull --png --open            # PNG ページも。終了時にフォルダを開く
```

出力: `~/Grimoire/<フォルダ>/<ノート>.pdf`（および `<ノート>/page-NNN.png`）。
`$GRIMOIRE_OUT` で変更できます。

SSH モードは `$GRIMOIRE_HOST`（初期値 `kindle`）から `/mnt/us/grimoire/notebooks/` を
`~/Library/Caches/grimoire` に rsync し、`build/host/grimoire-export`（`make tools`）を実行
します。増分式で、前回の書き出し以降に変わったノートだけを再レンダリングします。

`grimoire-export [--png] [--zip] [--force] <grimoire-root> <out-dir>` は、USB でコピーした
ものを含む `grimoire` フォルダの任意のコピーにも使えます。Kindle の Grimoire と同じリリースで
ビルドしてください（更新後はもう一度 `make tools`）。

## KOReader

KOReader は `grimoire/PDFs` の PDF をファイルブラウザから、またはプラグイン導入時は
**Tools > Grimoire > Notebook PDFs** から開けます。Grimoire はノートを変更後に閉じるたびに
PDF を書き直し、ノートの名前変更、移動、削除に合わせて PDF も移動・削除するため、KOReader が
そのファイルに書いたハイライトやメモは失われます。読むだけにして、書き込みたいときはコピーを
開いてください。
