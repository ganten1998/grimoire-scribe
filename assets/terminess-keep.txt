# The code points kept in assets/TerminessNerdFontMono-Regular.ttf and -Bold.ttf (the Terminess
# diet: Nerd Fonts' Terminess cut down to Terminus's text and the icons Grimoire uses). make
# fonts-subset (tools/fonts_subset.py, for the maintainer; assets/README.md) makes the two fonts
# from Nerd Fonts' release with exactly these code points. rust/tests/test_terminess_keep.rs checks
# that the embedded fonts hold exactly these, and that every icon the code draws is here.
#
# A line is one code point (U+XXXX) or a range (U+XXXX-U+YYYY); "#" starts a comment.
#
# Text: Terminus's own glyphs. A code point is kept where Nerd Fonts' file holds the very outline
# of Terminus TTF 4.49.3 (make fonts-subset checks this against the upstream files). That leaves
# out the 174 Nerd Fonts glyphs at ordinary code points: box drawing and block elements
# U+2500-U+259F (Nerd Fonts' own set, drawn over Terminus's), the heart U+2665 and the lightning
# U+26A1 (Octicons), the power symbols U+23FB-U+23FE and U+2B58, the menu sign U+2630 and the heavy
# angle brackets U+276C-U+2771. Grimoire's own screens and pages use none of them.
#
# Icons: Material Design Icons (Pictogrammers; Apache License 2.0), each one Grimoire draws or its
# 2.1 design plans. A new icon goes here, then make fonts-subset, or it draws nothing (the test
# says which is missing). Not kept: KOReader's own symbols at private use code points (its battery
# among them), which KOReader draws from its own symbols font.
